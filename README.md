# Gravit Docs

Documentation for the open tools of the Gravit Open Network Foundation, published at https://docs.gravit.space.
Built with [Starlight](https://starlight.astro.build). Pages are in `src/content/docs/`.

```bash
npm ci && npm run build      # static site in dist/
npm run dev                  # local preview
```

Corrections are welcome: every page has an "Edit page" link. Licence: Apache-2.0.
