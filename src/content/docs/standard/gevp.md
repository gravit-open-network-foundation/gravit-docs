---
title: "The GEVP specification"
description: "The open specification behind every decision."
---

The Gravit Epistemic Verification Protocol (GEVP) specifies how signed evidence is checked, grouped by independent source and turned into a reproducible decision record. It is published as an Internet-Draft at the IETF: [draft-gravit-gevp](https://datatracker.ietf.org/doc/draft-gravit-gevp/). Internet-Drafts are individual submissions and are not endorsed by the IETF.

The reference implementation follows the current draft; every rule in the draft has a test vector that the code must pass in Python and in Rust.
