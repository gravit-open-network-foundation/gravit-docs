All code is open under Apache 2.0 at [github.com/gravit-open-network-foundation](https://github.com/gravit-open-network-foundation). Every change goes through a reviewed pull request.

## Core tools

| Repository | What it is |
|---|---|
| [verifier](https://github.com/gravit-open-network-foundation/verifier) | Gravit Verifier: the reference implementation in Python and Rust, 47 public test vectors |
| [gravit-verifier-service](https://github.com/gravit-open-network-foundation/gravit-verifier-service) | the hosted API, receipts, public receipt log and billing |
| [capability-gate](https://github.com/gravit-open-network-foundation/capability-gate) | fail closed permissions for AI agents |
| [history-keeper](https://github.com/gravit-open-network-foundation/history-keeper) | journals sealed with independent time |
| [graviteron](https://github.com/gravit-open-network-foundation/graviteron) | how strongly evidence supports a claim |
| [gravit-path](https://github.com/gravit-open-network-foundation/gravit-path) | lawful routes with official sources, rule packs and site |
| [gravit-eval-pack](https://github.com/gravit-open-network-foundation/gravit-eval-pack) | reproduces every published number of the verification stack |
| [gravit-docs](https://github.com/gravit-open-network-foundation/gravit-docs) | this documentation |
